Overview

The IRSST utility computes the adjusted average exposure value (AAEV) for work schedules other than the standard 8 hours/day, 5 days/week. It implements IRSST Technical Guide T-22 ("Guide for the Adjustment of Permissible Exposure Values for Unusual Work Schedules") and is built around Québec's regulated permissible exposure values (VEMP/PEV), with an approach that can be adapted to other limit systems.

Assessment Phase(s)

Applied to OELs after exposure assessment (limit adjustment)

Exposure Pathway(s)

Inhalation (airborne chemical permissible exposure values)

Tool Type

Platform
Computer-based / online utility
Output type
Adjusted exposure value (AAEV)

Use Cases (When to Use / Applications)

Adjusting permissible exposure values for workers on extended shifts (more than 8 hours/day) or extended or compressed work weeks (more than 40 hours/week), to support exposure-compliance decisions under Québec's Regulation respecting occupational health and safety (RSST) and, by adaptation, in other jurisdictions.

Inputs & Outputs

Inputs (What you provide)

The substance to be assessed (which, in the Québec implementation, carries a predefined IRSST adjustment category and its 8-hour TWA permissible exposure value) and the characteristics of the unusual work schedule (hours per day and days per week).

Outputs (What you get)

The adjusted average exposure value (AAEV) — the reduced 8-hour-TWA-equivalent permissible exposure value for the specified schedule — along with the substance's assigned adjustment category.

Known Limitations / Notes

  • Only the 8-hour TWA value is adjusted — ceiling values and short-term exposure values are not.
  • Adjustment categories and values are specific to Québec's RSST substance list; use in other jurisdictions requires adaptation.
  • Substance data reflect a particular edition of the Québec regulation; confirm the current edition before relying on specific values.

Authors / Developers
