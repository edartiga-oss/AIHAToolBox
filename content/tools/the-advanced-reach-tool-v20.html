Overview

Estimates worker inhalation exposure to chemicals based on a mechanistic model with an option of a Bayesian analysis. The user can refine the exposure assessment using measurements from a built-in exposure assessment database, or from user data. The model hosts a library of 117 exposure scenarios that include 1,944 measurements

Inputs & Outputs

Inputs (What you need)

Chemical name, CAS, (for liquids: vapor pressure in Pa, mole fraction of substance (or wt. percent), activity coefficient, liquid temperature), (for solids: wt. percent, dustiness) amount used, room size, ventilation, separation, surface contamination(housekeeping) NF/FF and secondary sources. Activity and activity subclass, activity duration. User is also able to describe activity by characterizing it with determinants such as quantity, flow rates, containment, LEV, secondary controls, work location, room volume, ACH

Outputs (What you get)

Generates an exposure estimate in mg/m3 at a selected percentile and confidence interval. Users can add Bayesian treatment to the data by either uploading their own monitoring data, or selecting analogous scenarios, in which case monitoring data affiliated with those scenarios will be used. Both the mechanistic and Bayesian results are displayed. Report can be downloaded in pdf or excel.

Physical Form Details

The model contains an input called Product Type, which allows the user to describe the form of the product in which the substance is formulated or bound. The product type accomodates powders, granules, pellets, liquids incorporated into solid objects, liquids, dissolved powders, pastes, and slurries

Strengths

On-screen guidance is very helpful to understand the inputs. Users can do a Bayesian analysis of the scenarios using analogous data from a library of 117 exposure scenarios or by uploading their own analogous data. The model has helpful guidance on creating the data format to upload. Inputs allow users to choose between entering quantitative inputs or selecting from dropdowns when values are not known or available. Considered a higher-tier model. Examples of activities, including pictures, are offered to assist user in selecting the most appropriate scenario. Yields 8 hr. TWA and longer-term estimates Allows user to build an 8 hour day with up to four defined tasks. Allows for no exposure time period.

Known Limitations / Notes

Cannot assess fibers, gases, and dust from hot metallurgical processes. Not intended for consumer exposures. Can only be used for inhalation exposures.
