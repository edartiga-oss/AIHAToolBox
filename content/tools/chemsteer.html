Overview

ChemSTEER generates screening-level estimates for environmental releases of and worker exposures to a chemical manufactured and used in industrial and commercial operations (i.e. workplaces). The tool also contains data and estimation methods to assess chemical use in common industrial/commercial sectors (e.g., automotive refinishing) and chemical functional uses (e.g., tackifier in adhesive). ChemSTEER does not contain methods for estimating exposures to chemicals to the general public, to consumers, or to other species in the environment.

Inputs & Outputs

Inputs (What you need)

- General chemical properties - operation type (manufacturing, processing, use) - physical state - activity type (e.g. coating, cleaning, unloading/loading) - operation parameters (e.g. continuous operation/batch, raw material/product) - amount, frequency, loss fraction - default parameters - Release model

Outputs (What you get)

TWA inhalation (ppm), applied and absorbed dose rate (mg/day), lifetime avg daily dose (mg/kg-day), Acute potential dose (mg/kg-day)

Strengths

- Pre-loaded activity types available for certain manufacturing processes - 12 exposure metrics for outcome including: median, central tendency, worst case, what if and others - Incorporates EPA models that have been peer-reviewed

Known Limitations / Notes

- Default parameters may not be applicable for all scenarios; review closely - Learning curve for model use - Screening level assessments only -Multiple input parameters needed - Must ensure scenario fits a pre-loaded model; can be difficult to determine which model is most applicable - Cannot export all input parameters - Can only be used on Windows or Windows parallel
