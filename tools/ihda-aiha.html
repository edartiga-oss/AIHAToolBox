Overview

IHDA (the IH Data Analyst) is Windows statistical software for interpreting occupational exposure monitoring data. It calculates AIHA-recommended descriptive and compliance statistics, handles non-detect (left-censored) data, and produces Bayesian Decision Charts that give the probability an exposure profile falls into each of AIHA's exposure control categories. The edition hosted by AIHA (IHDA-AIHA) is a free, limited edition aimed at students and course participants; the full feature set is in the commercial editions.

Exposure Pathway(s)

Inhalation (airborne exposure measurements compared against an OEL)

Tool Type

Platform
Windows software
Statistical treatment
Descriptive, compliance, and Bayesian

Use Cases (When to Use / Applications)

Interpreting small occupational exposure datasets; computing AIHA-recommended descriptive and decision statistics; handling non-detects; and using Bayesian Decision Analysis to assign or validate the appropriate AIHA exposure control category for a similar exposure group.

Inputs & Outputs

Inputs (What you provide)

Occupational exposure monitoring datasets — airborne concentration measurements for a similar exposure group compared against an occupational exposure limit — typically small samples, including datasets that contain non-detects.

Outputs (What you get)

Descriptive and compliance statistics (such as percentiles and upper tolerance limits), goodness-of-fit tests and graphs, censored-data analysis results, and Bayesian Decision Charts giving the probability of each AIHA exposure control category (0–4).

Known Limitations / Notes

  • Windows-only (AIHA states it will not run on a Macintosh without an emulator).
  • Designed for small, single similar-exposure-group datasets using lognormal-based statistics.
  • The AIHA-hosted edition is a free / limited edition; the full feature set resides in the commercial editions from the developer.

Authors / Developers

Exposure Assessment Solutions, Inc. (EASi) — Paul Hewett, Ph.D., CIH.
